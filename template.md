## Conventions

- Every document starts with a `# Title` followed by a `## Table of content` section
  with links to all `##` sections of the document.
- Sections listed in the table of content must be level `##` headers. Use `###` only for
  sub-sections that are not listed in the table of content.
- Use `{placeholder}` for variable parts of commands, for example: `{user}@{server_ip_address}`.
- Use `sh` for shell code blocks and `cmd` for Windows command prompt blocks.
- The documentation language is English.
