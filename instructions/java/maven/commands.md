### Wrapper Installation

Maven Wrapper plugin [official documentation](https://maven.apache.org/wrapper/maven-wrapper-plugin)

1. First, we need to go in the main folder of the project and run this command
    ```sh
    mvn -N wrapper:wrapper
    ```
2. We can also specify the version of Maven
    ```sh
    mvn -N wrapper:wrapper -Dmaven=3.6.3
    ```
