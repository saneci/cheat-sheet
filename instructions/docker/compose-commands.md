### Header 1

- Build docker images and run services specified in the docker-compose.yaml file 
   ```shell
   docker compose up --build
   ```
- Stop docker compose services and remove images 
   ```shell
   docker compose down
   ```
- Show running services
  ```shell
  docker compose ps -a
  ```
- Run service
  ```shell
  docker compose run {service_name}
  ```
- Stop service
  ```shell
  docker compose stop {service_name}
  ```
