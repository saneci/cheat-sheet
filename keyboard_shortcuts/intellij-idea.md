### File

- `Ctrl+D` - compare any two files or folders, select them in the Project tool window
- `Ctrl+N` - open any class in the editor quickly


### View

- `Ctrl+Alt+Shift+S` - project structure  
- `Ctrl+Space` - show Lookup menu with matching suggestions  
- `Ctrl+Shift+I` - quickly review definition or content of the symbol at caret, without the need to open it in a new editor tab  
- `Ctrl+H` - open class hierarchy  
- `Ctrl+F12` - show class structure  
- `Alt+F1` - open the Project tool window and switch focus to it


### Navigate

- `Ctrl+Alt+F7` - view the list of all usages of a class, method or variable across the whole project, and quickly navigate to the selected item  
- `Ctrl+B` - go to a declaration  
- `Ctrl+Alt+B` - go to an implementation(s)   


### Code

- `"sout"+Tab` - print 'System.out.println()'  
- `Alt+Enter` - import necessary library
- `Ctrl+Shift+Enter` - complete a current statement such as if, do-while, try-catch, return (or a method call) into a syntactically correct construct (e.g. add curly braces)  
- `Alt+Insert` - generate (constructor, getter, setter, etc.)  
- `Ctrl+Alt+T` - surround with...  
- `Ctrl+Alt+V` - create variable based on specified class (for example, start typing `new ClassName()` and then press `Ctrl+Alt+V`)  
- `Ctrl+j` - postfix code completion is applied from right to left to avoid backward caret jumps when coding 
(type a dot `.` after the code fragment that you want to change and select the desired option)
- `Ctrl+Shift+Space` - the Type-Matching completion after the `new` keyword to instantiate an object of the expected type


### Find and replace

- `Ctrl+F` - display the search bar  
- `Ctrl+R` - add another field where you can type the replace string  
- `Ctrl+Shift+R` - you can switch to replace in the `Find in Files` dialog  
- `Ctrl+Shift+F` - hide the `Replace with` field and switch to regular search  
- `Ctrl+Shift+N` - open any file in a project
- `Alt+F7` - find usage  
- `Ctrl+Alt+Shift+Insert` - scratch files are temporary files that let you experiment and prototype in the editor, without creating any project files
